# PhotoFitter

PhotoFilter lets you filter your photos and videos by date.

## Hou to use PhotoFilter

You can access [PhotoFilter's documentation](https://photofilter.fr/documentation/) on PhotoFilter's website.<br>
You can also access it by pressing F1 while using PhotoFilter.
